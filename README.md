# Toman Bike Share – Sales & Revenue Analysis

End-to-end analysis of bike-sharing data to explore revenue, rider demographics, seasonal trends, and pricing opportunities — using **SQL (PostgreSQL) and Power BI**.

## Project Overview

This project analyzes bike-share ridership and revenue data to understand rider behavior and usage patterns, and to support data-driven pricing decisions.

## Tech Stack

- **SQL** — data cleaning, transformation, and business-question queries
- **Power BI** — interactive KPI dashboard

## Process

1. **Data Cleaning & Transformation (SQL)**
   - Cleaned raw ride/transaction data
   - Explored revenue trends, rider demographics, seasonality, and usage patterns

2. **Analysis**
   - Investigated pricing and rider behavior patterns
   - Identified an opportunity for a **10–15% price increase**, with a recommendation to monitor customer response before rolling it out further

3. **Dashboard (Power BI)**
   - Built an interactive dashboard visualizing key business KPIs and trends (revenue, ridership, seasonal patterns, demographics)

## Key Insight

Pricing and rider behavior analysis revealed room for a moderate price increase (10–15%) without expected major drop-off in usage — recommended to be rolled out with careful monitoring of customer response.
